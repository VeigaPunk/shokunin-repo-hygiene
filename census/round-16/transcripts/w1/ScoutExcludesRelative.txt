176:**Relative `core.excludesFile` / `core.attributesFile` are resolved against the process CWD, not the worktree top.** Git performs no anchoring: `interpolate_path()` (path.c:704-745) only expands a leading `~/` (raw `$HOME`, no `realpath` since `git_config_pathname` calls it with `real_home=0`), `~user/` via `getpwnam`, and `%(prefix)/` → runtime prefix, then copies the remainder verbatim. `environment.c` stores it unchanged (:155-163, :492-495), `dir.c:3505-3508` and `attr.c:885-886,932` hand it straight to `open`. Docs confirm by contrast: `core.worktree` says ".git-relative" (:2849-2850), `diff.orderFile` says "relative to the top of the working tree" (:3558-3559), `include.path` says "relative to the configuration file" (:1076-1077) — the two entries in question carry **no base clause**. If `$HOME` is unset, git dies: "failed to expand user dir in".
