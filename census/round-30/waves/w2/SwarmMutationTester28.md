## Findings

1. **False red in the committed A1 instrument (measured).** `strip_err` (census/round-30/c2-counter-v2.py:69) anchors on a tab (`\terr=`) while the gate selftest's CASE detail puts `err=` after a space (tools/souji-landing-gate.py:1425), so the tolerated err-tail difference is never stripped and `regress_full=differs` prints at the tip (and at 68447af). The A1 target `regress_full=same` is therefore unmet at the final lane tip by the committed counter itself. Direction is false red (blocks, never ships) — but it red-flags the round's own target for a difference the counter's docstring says to tolerate. Fix belongs to the L1's integration pass, not to this read-only seat.
2. **No committed control independently re-derives the REGRESS verdict.** The frozen v1 REGRESS is last-line-only (census/round-30/c2-counter.py:113) and prints `regress=same` at the tip (measured), so mutants m5/m6 — which flip v2 to a false green (`regress_full=same`, exit 0) — would stand under both committed instruments. Exposure of a swapped-in m5/m6 is only the diff against the recorded pristine receipt; nothing committed recomputes the full-line comparison.
3. **NOCAP accepts any COULD-NOT-EVALUATE regardless of reason** (census/round-30/c2-counter-v2.py:121-122). Measured under m7: the gate's CNE for an unresolvable revision (`rc=2`) satisfied NOCAP (`NOCAP rc=2 ok`). BIND's SUMMARY requirement partially backstops a gate that always CNEs (no SUMMARY → `reports=-1` → bind fails), but a gate that prints a green SUMMARY and CNEs on demand passes both legs; the CNE reason is never checked.
4. **Five guard clauses are vacuous at the committed tip** (m1, m2, m3, m4, m8: outputs byte-identical to pristine). Each clause demonstrably bites on its planted state (all KILLED-ADVERSARIAL), so none is dead code — but the committed round run never exercises them, so the committed green is not evidence that these clauses fire; their protection exists only against states a future dishonest lane could plant.
5. **Committed-input facts at the C2 landing commit 68447af** (measured): the v2 counter's BIND leg is red there (`dangling=1`, SCORECARD.md:322 cites `.ufo/waves/round-30/w1/deliver-c1-literal-history.tsv`, resolved only by the later round-30 capture commit) and 7 `LG-SEAT-UNCARRIED` findings stand (resolved at 936efc8). The gate counts reports from the wave prefix first and falls back to the capture (tools/souji-landing-gate.py:480 `p for p in tree if p.startswith(wave_prefix) and p.endswith(".md")`), which is what makes the m2 planted state (committed .ufo copies) reachable at all.
