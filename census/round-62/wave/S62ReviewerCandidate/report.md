### Named limits

- L1. End-to-end reachability for tag letters other than H/S/h is not achievable through the git CLI on this version (git only emits supported letters); verification of non-H/H unit tag bytes was done at the parse-loop level. The refusal is structurally total for any byte ≠ `H` at record position 0.
- L2. `cannot read index flags` is reachable only when `git ls-files` fails while earlier refusals (rev-check, dir-check, cat-file) do not fire first; my corrupt-index probe instead triggered `status`'s error first. Reachability confirmed via a hostile `GIT_INDEX_FILE` env passthrough (F11) — the tool scrubs only `GIT_DIR`/`GIT_WORK_TREE`. Spec should note: `cannot read index flags` will surface in practice as a late-stage, environment-dependent failure, not as the natural failure of a not-a-repo root.
- L3. The check `git ls-files -v -- <path>` per-file was used to verify the tag for a single file in each fixture; the fixed driver does not differentiate "flagged and deleted" from "flagged and unmodified" — one class per the frozen spec.
- L4. Fixture repos were created with `mktemp -d -p $S` + `git init -q` with top-level check (`git rev-parse --show-toplevel` equals the fixture dir) before first commit; identities were throwaway (`user.name=cand`, `user.email=cand@x`); read-only git (`log`, `show`, `cat-file`, `rev-parse`, `ls-files`, `ls-tree`, `status`) was used in the lane itself. No mutation of production paths, index flags, or jj state.
- L5. The r60 fixture command as published takes `--work` (required); the round text's fixture-line omits it. Run command used: `python3 clone/tests/fixtures/r60-receipt-write.py --tool clone/tools/souji-receipt-write.py --work r60work` → rc 0.
- L6. One line of speculative design review (not enforced by the frozen matrix): the rule's tag census reads every index entry, not just the bound instrument — this broad refusal class means a *benign* skip-worktree on an unrelated file (e.g. `config.h` pinned by a developer tool) makes the lane unwritable. The lane census probe (F1) shows zero flagged paths today, so this limit blocks no honest run today, but it is a forward-facing constrain on seat acceptance; frozen design consciously accepts this (the claim is written as an unconditional refusal).
