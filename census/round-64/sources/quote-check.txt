offsets are BYTE offsets into the named file; "line" is 1-based (1 = first line)
captures/<name>.html = raw bytes exactly as fetched by curl (not re-rendered)
captures/<name>.txt  = tag-stripped text of the same bytes
captures/<name>-located-quote.txt = the single documented entry excerpted from the SAME fetched bytes
stripping rule for *.txt: <script>/<style> and HTML comments removed; every remaining tag -> a single space;
  HTML entities unescaped; NBSP (U+00A0) -> space; runs of spaces/tabs/CR collapsed to one space; blank-line runs collapsed.
  In-sentence line breaks therefore remain as newlines in the .txt file; a quote is located by a whitespace-tolerant
  match and the reported offset is the offset of the FIRST matched word.
located-quote recipe: the entry's own HTML element is cut out of the SAME fetched bytes (by its anchor id),
  then every tag -> nothing, entities unescaped, NBSP -> space, all whitespace runs -> one space, trimmed.
  The result is a byte-contiguous copy of the documented sentence: the offsets below are asserted mechanically
  by slicing the capture bytes and comparing to the quote bytes (assert output pasted under each entry).
