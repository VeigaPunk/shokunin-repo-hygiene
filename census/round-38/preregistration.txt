### A8 — A1 revision 2 (2026-10-28, wave-2 seat W2RevC2 F1/F4)

A1 removed the docstring from the token stream with `str.replace(doc_raw, "", 1)`, comparing the
DECODED docstring value against tokenized source text; a docstring containing any escape made the
replace a no-op, leaving the docstring in the code text and the phantom arm blind (measured: a
phantom class with `\t` read PASS). The docstring token is now excluded by its AST span
(`ast` node start position), and the behavioural assertions (`JSON-NOT-REGULAR`,
`JSON-IS-RECORD`, `JSON-INSIDE-MEASURED-TREE`, `JSON-HARDLINKED`, `RECORD-OUTSIDE-ROOT`) use
whole-token matching. Landing 12/12, base arm `base_fail=6 behavioral_fail=3`; the escaped-phantom
variant now reads `phantom=['JSON-PHANTOM']`. Case id and count unchanged.

### A1 — docstring-enum tightening (2026-10-28, wave-1 seat W1RevDocstring)

The C2 `docstring-enum` case read the first triple-quoted literal (`source.split('"""')[1]`) and
matched raw substrings, so it false-rejected a raise form inside a comment (variant a1), accepted a
triple-quoted module constant as the docstring (b1), accepted a doc-only phantom class (d), accepted
a class name degraded to a prefix (d2), and missed the tool's second exit-2 idiom
`REFUSAL <TOKEN>:` written to stderr (c2). The case now reads the module docstring through
`ast.get_docstring`, drops comment tokens before collecting code tokens, collects both refusal
idioms, removes the docstring token from the code text, and matches whole tokens in both
directions. Case id and count (`cases=12`) and the frozen predicate are unchanged; the case is
strictly stronger. Evidence: `census/round-38/records/a1-docstring-variants.txt` (a1 now PASS;
c2, d and d2 FAIL; landing 12/12; base arm still fails the four routed classes).

### A4 — record open is non-blocking (2026-10-28, wave-1 seat W1SentEnvelope F1/R3)

`parse_record` checked `os.path.isfile` and then called a blocking `open()`; a path swapped to a
FIFO between the two hung the run forever (the seat reproduced rc 124 at 20 s on run 0 and run 7 of
two variants). The record is now opened `O_RDONLY|O_NONBLOCK` and the descriptor is checked with
`fstat` before any read; a missing path keeps its `RECORD-MALFORMED` class and every existing case
is unchanged (`cases=10 pass=10 fail=0`).

### A5 — a kill needs the fixture's own failure field (2026-10-28, wave-1 seat W1RevBattery)

The battery counted any literal `=FAIL` line plus any SUMMARY as a kill, so a fixture that printed
one `=FAIL` line and a SUMMARY and then crashed scored `killed` (the seat's probe:
`killed=4 ... pristine=FAIL`). A kill now requires the fixture's own `SUMMARY ... fail=N` with
`N > 0` and no `Traceback` on either stream; the four mutants still read
`killed=4 survived=0 pristine=ok`.
