**Verdicts on the six assigned questions**

1. **`set -m` — holds.** Without it the child shares the parent's group (`pgid=399621` = parent); with it `pgid == pid` (`399685`), including inside a function. Silent on a tty-less pipe-stdout script; no `[1]+ Done` noise; the child's stdin becomes `/dev/null` (proven: `head -1` returns `rc=0` on EOF).
2. **Group TERM frees a FIFO-blocked git — holds; pid-only provably fails.** git blocked in `open(2)` shows `wchan=wait_for_partner`; `kill -TERM -- -<pgid>` → DEAD, `wait` rc **143**; SIGKILL → **137**. Killing **only the bash parent** leaves the git child alive, reparented to 1497, still blocked — the exact 58-process leak mechanism. And the group survives its shell's death: a killed subshell's child reparents to init **keeping its pgid**, which `killpg` then still reaps.
3. **`EXIT` trap — child never runs the parent's.** The subshell sees the definition (`trap -p`) but does not execute it; its own trap fires on exit and on TERM. A parent `EXIT` trap fires on normal exit, `exit 2` mid-loop, and external SIGTERM. So **one shared `mktemp -d` + one `rm -rf` trap is safe** (verified across 3 forked iterations, dir intact; removed on `exit 2`).
4. **`$( … )` + watchdog — holds only with `>/dev/null 2>&1`.** Redirected: capture returns in **1 ms** with the watchdog still sleeping. Unredirected: capture blocks **30005 ms** (watchdog holds the pipe) and injects its output into the captured row. Same at the fix's exact shape: **3010 ms**, `out=[ROW\nLATE]`. The watchdog also needs its own `set -m` group, or `kill $wpid` orphans its `sleep` (ppid → 1497).
5. **`set -e` + `wait` — fails bare.** `souji-census.sh:161` is `set -euo pipefail`; bare `wait` on a killed child aborts the script (exit 143), and even a plain `( )` returning 4 kills the outer shell. `wait … || rc=$?` and `if wait …; then/else` both work. Double-wait returns **0**, not 127.
6. **Contract trap found: `137` is ambiguous.** A repo killed externally by SIGKILL is indistinguishable from the watchdog's escalation, so `error`-row attribution must come from a **sentinel written before the first signal**, tested after `rc=0`. With it: rc 137 and no sentinel → `census failed (rc=137)`, exit 1; sentinel → timeout row, exit 0.
