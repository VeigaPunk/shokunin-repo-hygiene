## Findings (survivors, classified)

* **F1 — `--max-output` Fatal is redundant under killpg.** Dropping the `raise Fatal…` line (PM3) survives the predicate and every stream direct: the killpg lands before any finite fixture finishes writing, so the returncode path looks identical. The cap's value is the *wording* of the Fatal, not the exit code; no arm distinguishes them.
* **F2 — the counter does not check output-stream when both are quiet.** PM5/PM10/PM6 survive because the twenty arms never produce a bare OSError, an internal exception, or a `--timeout 0` with a wrong message. Exit-code-only discrimination leaves the three `cli()` handler mutants alive.
* **F3 — arm-timeout default is load-bearing but unasserted by wording.** CM4 (17 s) is killed via S12/T1 `hung`, but the conform summary conflates it with other failures. No survivor here; noted for contrast.
* **F4 — PM11 (kill vs killpg) is masked by counter reaping.** The counter's own T1 reap closes the loop the probe's group-kill would have left open; the predicate cannot tell which component killed the grandchild.
* **F5 — CM1/CM7 counter mutants survive the predicate** because the decoy test runs a full arm and the snapshot happens before its process appears in a discriminating way; observed with `cm_decoy_direct.py` (decoy preserved by both pristine and mutants). The threat model (foreign token process) survives the counter.
* **F6 — CM8 (conform `or`) gives the r96 probe 20/20 — a broken counter** by the acceptance criterion ("a counter mutant that gives the r96 probe 20/20 is a broken counter"). Measured: CM8 on the r96 probe conform=20 exit 0 (receipts/cm8-r96.txt).
* **F7 — PM3 on the r96 suite: conform=20 (receipts/full-pm3-r96.txt)** — the twenty-arm table gives no over-cap fixture, so the r96 probe's larger cap is never crossed. Same finding as F1.

## Falsification declarations

### FALSIFIES-WORDING

1. The C2 predicate wording "`ARM T1 exit=2 want=2 line=yes conform=yes survivors=0`" is used to kill CM2 (no reaping). The counter mutant CM2 (reap dropped, counting honest) yields T1 `survivors=1` and conform=20 exit 0 (receipts/cm2-r97.txt, receipts/cm2-r96.txt). The predicate as worded DOES discriminate CM2 via the survivors byte, so the wording holds for CM2.
2. The statement "a counter mutant that gives the r96 probe 20/20 is a broken counter" (assignment criterion) is realized by CM8: it gives the r96 probe 20/20 (receipts/cm8-r96.txt). The C2 claim's predicate (conform=20) cannot distinguish CM8 from the pristine counter by its summary alone, so the predicate's conform number is insufficient to certify counter integrity against this class.
3. `PM3-no-overcap-fatal` and `PM8-no-total-accum` survive the predicate AND the directs (streaming fixtures). The claim "a fixture over the cap is a setup failure" is true for the probe's exit code in every experiment, but the probe's *Fatal wording* for that refusal is unasserted by any arm: a mutant that silently buffers-and-returns-the-same-exit is indistinguishable.

### FALSIFIES-NUMBER

Numbers re-derived: baseline conform=20 r97 (receipts/base-r97.txt), r96 probe on r97 counter conform=20 survivors=0 (receipts/pred-r96-on-base.txt), PM1 conform=19 T1 hung (receipts/pred-r97-on-PM1.txt), PM2 conform=19 S12 hung (receipts/pred-r97-on-PM2-no-timeout-killpg.txt, receipts/full-pm2-r96.txt), CM4 conform=15 (receipts/cm4-r97.txt, receipts/cm4-r96.txt), CM3/PM9 conform=3 (receipts/cm3-r97.txt, receipts/full-pm9-r97.txt), CM5 conform=19 (receipts/cm5-r97.txt), CM6 conform=17 (receipts/cm6-r97.txt).

## NO-FALSIFICATION

No finding falsifies a **number** ("ARM T1 survivors=0" and "ARMS-SUMMARY arms=20 conform=20" reproduce on pristine bytes). The falsifications above are about the predicate's **discrimination power** and the claim wordings' reach, not about falsified counts.
