Multi-section reading is exercised only by synthetic fixture cases G3/G10. A tool that still misses real mid-file sections (rounds 15/19/23/24/25, per prereg line 22) can satisfy the entire target SUMMARY. The axis-check R4 does not catch this: it scans only the MACHINE BLOCK, and any block with an `enumerate:` line passes regardless of what the command enumerates.
2. [LOW — claim text vs counter semantics] C1's claim: "every enumerated cell literal is bound to an observable that shows it at the revision" (prereg line 5). The frozen counter permits a superseding `run:` row to state a different literal: `BAD-ROW(line-or-literal)` requires only the same base line and >=2 integers (`tools/souji-capability-cells.py` lines 214-238), and MATCH checks the row's literal against the command output. Record rows must preserve the base integer multiset. So an item like L06 (enumerated literal 18/18, selftest prints 65/0) can be resolved by appending a row stating 65/0. That is supersession of the count, not "binding" of the enumerated literal; the sentence overpromises.
3. [LOW — prose count] C1 paragraph: "and 23 literals have no observable beside them at all" (prereg line 5). The frozen counter's base reading is `unbound=22` (controls.tsv; c1-before.txt). The 23 appears to be 41 minus the r30 `rows=18`, but the instrument's own count is 22. Prose only; target/counter unaffected.
