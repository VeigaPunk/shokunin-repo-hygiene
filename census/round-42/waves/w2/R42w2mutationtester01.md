## Method

1. **Axes.** The surface changed is the tool (C2 operability). The judged instruments are the frozen counter `census/round-42/c2-counter.py` (sha256 `fa44392d...`, read at the tip) and the tool's own `--selftest`.
2. **Mutants.** `scripts/mutants.py` makes 64 single-point mutants. Each is one `str.replace(old, new, 1)` on one anchor that the script asserts occurs exactly once in the tip bytes. Every mutated line is between 43 and 187 (`manifest.tsv`). Kinds: regex 12, const 8, cond 8, expr 7, class 6, args 5, branch 5, call 4, env 2, stmt 2, and one each of assign, guard, index, order, path. 62 mutants replace one line with one line; M22 and M59 delete two lines each. Mutant sources are in `mutants/`; unified diffs are in `diffs/`.
3. **Scoring.** `scripts/run.py` runs, for each mutant: `score-candidate.sh c2 <scratch> tools/souji-freeze-check.py=<mutant>` (the counter over the lane tip plus the mutant), and `python3 -B <mutant> --selftest` directly. The "counter cases" column is the counter's `pass/fail` over its 37-case table, and the kill decision uses only that column. The other legs (`real`, `retro`, `retro_clean`, `selftest`, `patches`) are recorded in `results.tsv` and `counter-summaries.txt`.
4. **Survivor triage.** Each survivor was run against the pristine tool and the mutant on synthetic git repos or on the lane's own preregistrations (`scripts/probe*.py`). A survivor is a GAP when the two differ on some probed input. It is EQUIVALENT when the two agree on every probed input. Probes 1-4 compare the exit code and the sorted `FINDING` lines; probe 5 compares exit code, stdout and stderr in full. Agreement on probed inputs is evidence, not a proof for all inputs.

## Interpretation for the L1

- The 37 counter cases and the 31 `--selftest` cases kill the same 39 mutants. On this set `--selftest` adds no kill the counter table misses, so the two instruments share a blind spot rather than covering each other.
- The 13 uncaught gaps fall into three groups of unexercised input: non-canonical spellings (uppercase hex, a 41-character `--rev`, trailing blanks, a BOM, trailing text on the control line); repository states the fixtures never build (replace refs, a NUL in a path, the prereg added twice, a dispatch file re-added after the freeze); and class labels or fallbacks never reached (the missing Round class, a digest-less value with trailing text, a duplicated key with an empty first value).
- The two lane-leg-only gaps show that the counter's `real` and `retro_clean` legs carry more of the kill load than the 37-case table. This is the strongest evidence in this run that the case table is the weaker half of C2.
- Nothing here changes a frozen file. Under the preregistration's rules, each gap is a named limit for the round lesson, not a reason to edit `census/round-42/c2-counter.py` or `tools/souji-freeze-check.py`.

## Limits of this run
