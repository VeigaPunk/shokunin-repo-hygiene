## Calibration findings (carry mechanism)

1. **Wave-2 reports move under the scanner.** Between scans, `RerunGateSelftest.md`'s STATUS moved 179→182 **and its wording changed** ("…no case runs a matching measured check…" became "…two cases pass with the named mechanism dead…"); `ScoutLsFilesPathspec.md` moved 170→173→177 **and its STATUS text was rewritten** (from "…in the `ls-files`→`check-attr` exclusion" to "…in the exclusion set for both consumers"), so the row drafted from the earlier scan would **not** have carried the rewritten line; `ScoutOptionalPrefix.md` moved 236→238; `ConnQuality2.md` oscillated 204↔205 as its seat appended prose; and `CriticR4Laundering.md`, `RerunGateReplayR14.md`, `RevengeSeatViolations.md`, `CriticFixtureRound2.md` and `RevGateSnapshot.md` appeared only after the first cutoff. The gate's detail reports a line number, but carry is text-only: any report rewrite after the lesson table is drafted breaks `LG-SEAT-UNCARRIED` for that row even though the *failure* is carried. Freeze the w2 reports before committing the lesson and the report, then run the gate last; do not trust this snapshot's line numbers.
2. **Snapshot, not final.** 29 report files carried grep hits at the last scan, and that set was still growing between calls. The landing gate is the authority for the final set; use the pinned predicate and the table shape above for the delta.
3. **First-token punctuation and quoting are real evasions.** `STATUS: INCOMPLETE,` (comma) and `` STATUS: `INCOMPLETE` `` (backtick) state the same failure and are silent — demonstrated live by `CriticC2Calibration.md:88-90`. So are `STATUS: F1 is open` and `STATUS: SURVIVED`. The lesson's broader list is the only place those survive; do not replace it with the channel-only table.
4. **Fence/table parity.** `startswith("```")` toggles on four-backtick fences too; `ConnLogConvention.md:221` is excluded only because of that. If an editor removes or rebalances that fence, `:221` becomes channel — but its normalized text is identical to `:385`, already carried, so the existing row still satisfies it. Conversely, do not put the wave-2 rows inside a fence or table in the **lesson**: `failures_section_lines` does not apply the report-side fence/table exclusions, so a fenced table would carry literally (the fence line text would simply not match any needle), but a heading would end the section.
5. **Section boundary is any heading.** A `### Round 16 wave 2` subheading after the wave-1 bullets makes every row under it invisible to `failures_section_lines` (it breaks at the heading) and all 28 wave-2 lines go `LG-SEAT-UNCARRIED`. Put the rows under the same `##` heading, separated only by a plain paragraph or bold lead-in.
6. **Multi-line STATUS values carry only their first physical line.** `ReopenS048.md:102`, `RerunGateFixture.md:12`, `ScoutLsFilesPathspec.md:179`, `ScoutOptionalPrefix.md:238`, `RerunSeatAudit.md:157` and `CriticHonestyAudit.md:184` end mid-sentence. The needle is exactly that truncated line; a table cell that quotes the continuation instead, or ellipsizes the first line, does not carry.
7. **`LG-OPEN-ADMITTED` gates the admission language.** All 28 wave-2 rows are open at the snapshot. If the lesson is to say `admitted: true`, every open row fires `LG-OPEN-ADMITTED` (gate:351-357). The lesson at `163158a` has no `admitted: true` literal, so a green there is consistent with open rows; add the literal only after the rows are resolved, or accept the findings.
