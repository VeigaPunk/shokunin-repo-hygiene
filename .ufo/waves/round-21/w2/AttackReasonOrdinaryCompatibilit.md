# AttackReasonOrdinaryCompatibilit — C3 ordinary-path sink

## Result

No ordinary-path mismatch or reason-field leak is exposed by this source-only trace. The bounded contract is: an ordinary, non-secret path is preserved in the reason when the formatted reason is at most 160 bytes; a longer reason is cut to its first 160 bytes. Control bytes become spaces and recognized secret-pattern matches are intentionally altered, so neither is byte-exact raw-path output. Existing short r18/selftest expectations remain below the new limit. This is a source reconstruction, not an observed test pass.

- For argv, `read_argv_stream` starts with no selected path and no secret provenance (lines 258–263). It computes a candidate from an absolute argument or `--*=/*`, and records the first vanished candidate under a configured prefix together with that argument's secret flag (lines 269–282). Each argument's pattern result is evaluated separately; only the explicit `--token`-then-next-argument state carries provenance to the following argument (lines 263–268, 284–289). `CMD_RAW` is assembled separately at lines 284–290.
- The census sends only the selected path and its provenance to `format_reason` (argv lines 384–388; fd lines 389–394). It separately sends `CMD_RAW` to `redact_command` (lines 403–405) and emits the already-formed `safe_reason` as one TSV field (lines 406, 408–415). Thus cmdline-wide redaction is not the reason-field input.
- A fabricated ordinary canary matching the fixture's `*-plain` cases is `worker\0/var/tmp/souji-r21-canary-<12 hex>/ordinary/file\0` (fixture lines 53–54, 79–82). The path has no recognized pattern/control bytes; the selected argument's `secret` stays 0, and the top-level `ordinary` component is absent under the declared prefix. `format_reason` therefore leaves the path unchanged. The fixture's exact expected lines are `argv-path-gone:<path>\n` (67 bytes for this fixed prefix/path) and `fd-path-gone:<path>\n` (65 bytes); its `*-plain` expectations require byte equality (lines 79–82). This is a bounded no-leak/no-mismatch trace, not a run.
- The adjacent fixture cases exercise the boundaries: control bytes are expected as spaces (lines 83–85), while a 400-byte `z` component is expected as the first 160 bytes of the formatted reason plus newline (lines 86–88). This matches the formatter's cap; full-path equality is not claimed above the cap.
- The existing selftest constructs a path argument separately from its other synthetic secret arguments (lines 541–551, 573–576), then requires the exact `argv-path-gone:$gone_path` reason while checking the command for secret removal (lines 640–648). Its fd assertion requires `fd-path-gone:$fd_path` (lines 651–652). The r18 fixture likewise compares exact reason/path concatenations for argv at lines 306–315, 533–540, and 734–740, and for fd at lines 624–633. These are the short legacy paths identified by the frozen assignment (at most 91 bytes), hence the 160-byte reason cap does not truncate them.

It does not extract baseline fd-link discovery, so this oracle checks the supplied fd-path sink, not descriptor discovery—appropriate to this assigned sink class.
