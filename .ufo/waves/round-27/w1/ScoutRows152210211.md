## Findings

1. **Escaped pipes `\|` inside cells break the contract census (hard schema defect).**
   SOURCES-CONTRACT-v1: "No `|` inside any cell." The contract census splits rows with
   `awk -F'|'` and requires NF=13 for every row ("malformed rows … must print 0").
   Awk treats `\|` as a field separator, so all three staged rows are malformed:
   - S152: anchor cell (`O_CREAT\|O_EXCL`) + teaches cell (`O_CREAT \| O_EXCL`) → NF=15
   - S210: recheck cell (`\| grep -F`) → NF=14
   - S211: recheck cell (three `\|`) → NF=16
   A simulation appending the three rows to a copy of `corpus/SOURCES.md` yields
   `malformed=3` (contract requires 0), so `sources-census.sh validate` would not be
   clean. The lane registry itself has 0 escaped pipes and 0 malformed rows. The
   tres must be rewritten pipe-free (see normalization table).
2. **Off-by-one line citations in the anchor cells (accuracy defect).**
   - S210 anchor cites "lines 2261, **2282**, 2284 and 2359". Line 2282 in
     `glocalfile.c` is **blank**; the descriptor-close line is 2281
     (`(void) g_close (fd, NULL);`), and the probe begins at 2284. The intended
     line is 2281.
   - S211 anchor cites "the `XXXXXX` template at **1367**". Line 1367 in
     `gfileutils.c` is **blank**; the template line is 1366
     (`tmp_filename = g_strdup_printf ("%s.XXXXXX", filename);`).
   All other cited lines (glocalfile.c 2256, 2261, 2284, 2288, 2340, 2354, 2359,
   2363, 2383, 2387; gfileutils.c 1041, 1108, 1369, 1697) verified correct.
3. **S211's `teaches` overclaims `G_FILE_SET_CONTENTS_ONLY_EXISTING`.**
   The teaches cell states the flag "makes the write fail rather than create a target
   that does not exist." The cited revision does not support that:
   - `gfileutils.h:91-94`: "@G_FILE_SET_CONTENTS_ONLY_EXISTING: Only apply
     consistency and durability guarantees if the file already exists. This may
     speed up file operations if the file doesn't currently exist, but may result
     in a corrupted version of the new file if the system crashes while writing it."
   - `gfileutils.c:1107-1112` (the flagged "handling at 1108") is the fsync
     decision in `fd_should_be_fsynced()`: on `ENOENT` it returns FALSE (skip
     fsync) — it never fails the write.
   - The ISTENT branch writes to a temp file and renames onto the destination
     (`rename_file` → `g_rename` at 1041); the direct branch opens with
     `O_CREAT` (line 1450). Neither branch refuses to create a missing target.
   Landing this teaches verbatim would put a false claim in an immutable cell; the
   claim must be corrected (see normalization) before admission.
4. **`recheck` cell prose deviates from the contract and lane convention.**
   Contract: "`recheck` — ISO date or cadence (`90d`, `180d`, `on-release`)." All
   132 lane rows carry a bare cadence token; zero rows have an em-dash prose

   (a shell command in S210/S211). Cadence `365d` is in lane vocabulary, but the
   prose+command form belongs in the knowledge entry's front-matter `recheck:`

5. **S211's recheck command is broken as written.**
