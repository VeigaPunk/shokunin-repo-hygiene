# Quarantine staging/digest history — round 13

**Scope axes:** calibration (source-grounded claims), operability (bounded stage/digest work), coverage (regression of hang/special-file failures).

## Reconstructed contract

The installed tool documents a five-stage per-target flow: stage 1 must re-derive `SAFE` with a receipt; stage 2 moves into `.ufo-quarantine`; stage 3 waits; stage 4 rechecks the receipt plus content/mtime pins; stage 5 deletes only after PASS. A stage-1 refusal leaves the target untouched; a stage-4 failure leaves the staged copy in quarantine and reports `ABORTED` (tool header, `tools/souji-quarantine.sh:33-72`). Exit 3 covers authorization refusals, aborts, and stage-2 failures (`:88-92`). Thus a bounded-call timeout or unsupported special file must become a per-target, diagnostic, non-success outcome; it must never flow on to deletion.

Q8 makes the missing operability contract explicit: per-target staging and digest calls are bounded with `timeout`, readers accept regular files only (and not symlinks), and hangs/special files fail closed with diagnostics; it also requires a stalled-target or FIFO regression (`corpus/QUALITY.md:32`).

## Minimal fix boundary (recommendation; no code changed)

1. **Preflight the target kind before the receipt engine or any digest read.** Keep the existing symlink/path checks; allow a regular file or a directory whose descendants pass the existing regular-file/symlink scope check; reject FIFO/socket/device/other special targets with an explicit per-target refusal and no move. Do not rely on a failed digest command as the type test.
2. **Bound only the per-target operations, not the whole quarantine session.** Add a fixed, documented timeout around each stage move (`git mv` / `mv`) and each target digest operation (file and directory-manifest hashing, including recheck paths). Capture timeout and ordinary errors explicitly. A move timeout must take the existing stage-2 failure path (exit 3, diagnostic, no stage-3/4/5 continuation); if source/destination state is ambiguous, stop and report it rather than deleting or silently rolling back. A digest error/timeout must be converted to a non-success per-target result before staging, or to an abort that leaves the quarantined copy intact after staging.
3. **Add focused behavioral selftests under a `/var/tmp` mktemp root with a cleanup trap.** A FIFO target must terminate promptly, report fail-closed diagnostics, and remain unmoved; a controlled stalled `mv`/`git mv` or hash operation must hit the internal bound, report a timeout failure, and never report PASS/DELETED. Keep tests confined to the fixture; do not use live deletion or treat a Q8 pass as deletion certification.
