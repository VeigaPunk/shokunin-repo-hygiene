## Method

- Read `census/round-95/preregistration.txt` (frozen contract) and the two instruments
  (`census/round-95/c2-forgery-probe.py`, `census/round-95/c2-setup-arms.py`).
- 10 one-edit probe mutants (PM1–PM10) and 3 one-edit arms-counter mutants (CM1–CM3)
  were generated by a small script (`gen.py`, in this dir) that asserts each replaced
  string occurs exactly once in the pristine source and writes the mutant beside it.
  Mutation points: `read_utf8`, the `makedirs` try/except, `write()`, the fixture-timeout
  kill signal, the `cli()` handlers and their return code, the `--timeout <= 0` check,
  the verdict return, and the `/tmp` work check (probe); S9–S14 want-codes/inputs, the
  per-arm timeout, and the stdout/stderr stream choice (counter).
- Probe mutants were scored with the exact C2 predicate command
  (`census/round-95/c2-setup-arms.py` with `--probe` substituted by the mutant).
  Counter mutants were scored twice: once with the r95 probe and once with the r94 probe
  (`census/round-94/c2-forgery-probe.py`) — a counter mutant giving the r94 probe 16/16
  would itself be broken.
- Detector: `ARMS-SUMMARY arms=16 conform=<k>` + counter exit code (0 iff k == 16).

## FALSIFIES-WORDING

Sentence: preregistration C2 CLAIM — "…refuses each of S9-S12 with exit 2 and a
`C2-FORGERY-FATAL:` line, and conforms on the twelve arms the r94 probe conforms on
(P1, P2, S1-S8, S13 a --work under /tmp, S14 a forgery edit that does not apply exactly
once)."
and INSTRUMENTS — "…S13 names an absent /tmp path it never creates".

Falsification: with PM9 (the probe's `/tmp/` startup-refusal prefix removed — one edit),
the C2 predicate STILL prints `ARMS-SUMMARY arms=16 conform=16` and exits 0
(receipt `results/P-PM9.out`), i.e. the predicate cannot distinguish "probe refuses a
--work under /tmp with a `C2-FORGERY-FATAL:` line" from "probe proceeds into /tmp and
produces *some other* `C2-FORGERY-FATAL:` line". The mutant passes S13 on a different
Fatal: `C2-FORGERY-FATAL: the fixture printed no SUMMARY line for the positive control
(exit 2)` — because both this run's r95 fixture and the r94 fixture abort with exit 2 ("Not a directory"-style, verified by direct reproduction with
the pristine probe and PM9, not in a receipt above by design-of-convenience but
reproducible by re-running them) when their `--work` is an existing /tmp dir that
becomes non-empty expectations-wise — more precisely when the positive-control fixture's
own `--work` path is under /tmp with a parent chain the fixture rejects. (See analysis
of the anomaly below.)

In other words: S13 as built checks **that some `C2-FORGERY-FATAL:` line appears on
stderr with exit 2**, not **the specific refusal** the claim describes. The predicate's
S13 line therefore does not bind the probe's `/tmp` startup check.

## PM9 deeper analysis (the stand-out survivor)

PM9 is a one-edit removal of `"/tmp/",` from the tuple
`("/tmp/", "/var/tmp/", "/dev/shm/")` in the probe's `--work` startup check. Expected:
S13 must break (exit 2 / FATAL / conform only via the /tmp refusal itself). Instead S13
still conforms. why? Let me re-verify carefully — because this surprised and my first
explanation was wrong. I re-ran the probe directly and on a real S13-shaped run:

- Pristine probe (`--work /tmp/...-absent`): exits 2 immediately with
  `C2-FORGERY-FATAL: --work under /tmp, /var/tmp or /dev/shm`. This is the intended refusal.
- PM9 (`--work /tmp/...-absent`): the startup check no longer fires. The probe proceeds:
  `os.makedirs(work, exist_ok=True)` **creates** the absent /tmp dir. The positive-control
  fixture run then launches — and the *fixture* errors out: the fixture's own `--work`
  (`<tmp>/positive`) is created, but the fixture's checks/r93-behaviour end with exit 2 and
  **no SUMMARY line on stdout**. The probe then raises
  `Fatal("the fixture printed no SUMMARY line for the positive control (exit 2)")`, which
  `cli()` prints as `C2-FORGERY-FATAL: ...` and returns 2.
- The counter's S13 check is `rc == 2 and any(line.startswith("C2-FORGERY-FATAL:") for line in stderr)`.
  Both conditions still hold — just by a different route. So the mutant is invisible.

Also worth noting: PM9 leaves the `/tmp/souji-r95-arm-S13-*-absent` directory behind (I
removed it), whereas the pristine probe never creates it. So the observable *difference*
is side-effect (leftover dir), not exit code or output line.

**Classification:** equivalent-in-form / arm weakness — S13 is an "exit 2 + line prefix"
arm where the expected Fatal message is more specific ("--work under /tmp"). The arms counter
holds S13 absent-paths by pid; the leftover PM9 dir is evidence the probe proceeded past the
startup check. (The r93 fixture independent sanity: the fixture's exit-2 under /tmp is itself
real behaviour—fixtures treat /tmp as forbidden too—but it is not the probe's refusal.)
