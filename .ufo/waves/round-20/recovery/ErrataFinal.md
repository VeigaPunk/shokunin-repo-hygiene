This verifies source structure, not a fresh run or authenticated execution.

**One concrete oracle change:** add a C1 case with a non-stem exact path, e.g. report `Seat.md`, prompt `DELIVER: /lane/.ufo/waves/r20/w1/shared-oracle.tsv`, and transcript write to that exact path.
